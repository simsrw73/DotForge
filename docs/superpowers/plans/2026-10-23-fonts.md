# Fonts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Detect a Nerd Font, turn optional icons off and say why when there is none, install one
with `Install-DFNerdFont`, and onboard font installers as tools.

**Architecture:** One private home decides whether icons are on (`Test-DFIconsOn`: the `NerdFont`
config key, else registry detection). Records and roles declare which of their behavior is icons
(role words, a plain picker preview, a `nerdFont: "required"` record field); core reads those
declarations and never names a tool. The installer is an on-demand command in `DotForge.Helpers`
whose side effects sit behind private seams.

**Tech Stack:** PowerShell 7.2+, Pester 6, Windows registry (`HKCU`/`HKLM` Fonts keys), `gdi32`
`AddFontResourceW` and `user32` `SendMessageTimeoutW` via `Add-Type`.

**Spec:** `docs/superpowers/specs/2026-10-23-fonts-design.md`

## Global Constraints

- `NerdFont` config key: unset = detection, `$true` = icons on, `$false` = icons off. Read only with `Get-DFConfig NerdFont`; add it to `$script:DFConfigKeys`.
- Fonts keys: `HKCU:\Software\Microsoft\Windows NT\CurrentVersion\Fonts` (values are full paths) and `HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts` (values are file names under `$Env:windir\Fonts`).
- Nerd Font name match (case-insensitive, on the value name with spaces removed): `NerdFont`, or a name ending in `NF`, `NFM` or `NFP` before the ` (TrueType)`/` (OpenType)` suffix.
- Never `[System.Drawing.Text.InstalledFontCollection]`.
- Not Windows: icons on unless `NerdFont = $false`.
- Load line, exact copy: `DotForge: No Nerd Font installed, so icons are off. Run Install-DFNerdFont, or set NerdFont = $true if your terminal already has one.` Not shown when `NerdFont` is set either way.
- One-time note, exact copy: `DotForge: Nerd Font installed: <face>. Select it as your terminal's font to see icons.` Only on an absent → present change, or after `Install-DFNerdFont`; the first detection ever records a baseline silently.
- Picker list for `Install-DFNerdFont`, in order, CaskaydiaMono first and preselected: CaskaydiaMono (`CaskaydiaMono Nerd Font`), JetBrainsMono (`JetBrainsMono Nerd Font`), FiraCode (`FiraCode Nerd Font`), Meslo (`MesloLGM Nerd Font`), Hack (`Hack Nerd Font`). Zip URL: `https://github.com/ryanoasis/nerd-fonts/releases/latest/download/<Name>.zip`.
- Install target `$Env:LOCALAPPDATA\Microsoft\Windows\Fonts`; one HKCU value `<file base name> (TrueType)` → full path per file; read access for `S-1-15-2-1` and `S-1-15-2-2`; `AddFontResourceW` per file; one `WM_FONTCHANGE` (`0x001D`) broadcast. No admin. Nothing installs during a load. No test installs a font or touches the real registry.
- Plugin rule: no tool names in core code. Every new alias checked against `Get-Command` (`docs/builtin-safety-policy.md`); this plan adds none.
- After touching `Shared/`, `Private/`, `Public/`: `./build/Build-DFCoreBundle.ps1`. After `Tools/*.json`: `./build/Build-DFToolRegistry.ps1`. Before committing: `./build/Build-DFReferenceDocs.ps1`.
- Commits are GPG-signed; batch them toward the end (one unlock).

## Review Focus

1. A Fonts registry value whose file is gone (font deleted by hand) must not count as installed. → Task 1 test.
2. A machine with zero matching fonts but a terminal bundling its own symbols (WezTerm): `NerdFont = $true` turns icons on and silences the load line. → Task 1 and Task 5 tests.
3. `Register-DFTool -Name eza` mid-session must follow the same gate as `Start-DFSession`. → Task 2 test.
4. `Install-DFNerdFont` run twice must skip files already installed and not duplicate registry values. → Task 6 test.
5. A non-interactive host without fzf and without `-Name` installs CaskaydiaMono and says so, never blocks on input. → Task 6 test.
